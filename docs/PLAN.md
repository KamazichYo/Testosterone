# Street Dogs Tycoon — план разработки

> Рабочее название. Тайкун про уличных собак: ловим диких собак в районах города,
> отмываем, кормим, лечим, вакцинируем, ставим бирку и либо возвращаем в район
> уже спокойными, либо пристраиваем в семьи. Город платит за работу, районы
> становятся безопаснее, приют растёт.

---

## 1. Концепция в одном абзаце

Город поделён на районы (Гаражи, Промзона, Рынок, Спальник, Парк, Вокзал…).
В каждом районе живут свои стаи: сначала дикие, то есть грязные, голодные и
злые. Игрок ходит по району персонажем (вид сверху), приманивает и ловит собак,
везёт их в приют и проводит через цепочку ухода. Обработанная собака получает
бирку на ухо. Её можно вернуть в район (растёт «спокойствие» района и доход
по городскому контракту) или пристроить (разовая выручка и репутация).
На деньги игрок улучшает приют, нанимает волонтёров, которые автоматизируют
станции, и открывает новые районы.

Реальная основа механики — программа **ОСВВ** (отлов → стерилизация →
вакцинация → возврат). Клипса или бирка на ухе у таких собак есть и в жизни,
поэтому «пломбирование» в игре — это бирка или чип.

## 3. Как запустить на телефоне без артефакта

**Рекомендация: веб-игра (PWA) на Phaser 3 + TypeScript + Vite.**

- Игра открывается по ссылке в мобильном браузере (Safari, Chrome).
- «Добавить на главный экран» даёт иконку, полноэкранный режим и работу офлайн
  (PWA: manifest + service worker).
- Бесплатный хостинг с автодеплоем при каждом пуше:
  - **GitHub Pages** через GitHub Actions (бесплатно для публичного репозитория);
  - для приватного репозитория: **Cloudflare Pages / Netlify / Vercel**
    (бесплатные тарифы).
- Позже ту же кодовую базу можно завернуть в **Capacitor** и получить APK или
  AAB для Google Play и сборку для App Store, ничего не переписывая.

Почему не Unity или Godot:
- **Phaser** — это чистый текстовый код. Его удобно писать и ревьюить вместе
  с ИИ, сборка занимает секунды, а веб-билд весит мегабайты, а не десятки
  мегабайт.
- **Godot 4** — хорошая альтернатива, если захочется визуальный редактор, но
  его веб-экспорт тяжелее и капризнее на iOS.
- **Unity** для 2D-тайкуна избыточен.

## 4. Core loop

```
 ┌──────────── РАЙОН ─────────────┐        ┌──────────── ПРИЮТ ─────────────┐
 │ найти собаку → приманить →     │  фура  │ мойка → кормёжка → ветпункт →  │
 │ поймать (мини-игра) → в фургон │ ─────► │ вакцинация/стерилизация →      │
 └────────────────────────────────┘        │ БИРКА                          │
            ▲                              └──────────────┬─────────────────┘
            │                                             │
            │   вернуть в район (+спокойствие, +контракт) │
            └─────────────────────────────────────────────┤
                                                          │ пристроить (+$, +репутация)
                                                          ▼
                              деньги → апгрейды станций, волонтёры, фургон, новые районы
```

### Мета-прогрессия
1. **Спокойствие района** (0–100 %) растёт с каждой обработанной собакой.
   На 100 % район «безопасный»: пассивный доход от донатов и городского
   контракта, открывается следующий район.
2. **Репутация приюта** открывает новые станции, найм, события и спонсоров.
3. **Собакодекс** — коллекция уникальных собак, у редких свои награды.

## 5. Ключевые системы

### 5.1. Собака (данные)
```ts
interface Dog {
  id: string;
  name: string;             // генерируется: Бублик, Шарик, Грета…
  look: DogLook;            // процедурно: окрас, уши, хвост, пятна, размер
  district: DistrictId;
  state: 'wild' | 'caught' | 'in_care' | 'tagged' | 'adopted';
  stats: {
    hunger: number;         // 0..100
    dirt: number;           // 0..100
    health: number;         // 0..100
    aggression: number;     // 0..100, падает с доверием
    trust: number;          // 0..100
  };
  vaccinated: boolean;
  sterilized: boolean;
  tagId?: string;           // номер бирки
  traits: Trait[];          // «Обжора», «Трусишка», «Вожак», «Ласковый»…
  rarity: 'common' | 'rare' | 'legendary';
}
```

### 5.2. ИИ собаки в районе (конечный автомат)
`Idle → Wander → (игрок рядом) → Alert → Flee | Aggressive | Approach (если есть еда) → Eating → Catchable`

- Агрессивная собака лает и бросается на игрока, отнимая выносливость.
- Голодная идёт на запах корма, это главный способ приманки.
- Вожак стаи: пока он дикий, остальные собаки стаи агрессивнее.

### 5.3. Ловля (мини-игра под телефон)
1. Кинуть корм (тап по собаке): собака подходит и ест, агрессия падает.
2. Подойти, пока она ест (пиктограмма «можно ловить»).
3. Мини-игра «доверие»: кольцо сжимается, тапнуть в зелёную зону. Сложность
   зависит от агрессии. Промах — собака убегает или кусается.
4. Инвентарь: корм, вкусняшки, сетка, петля-ловушка, клетка-переноска.
   Всё улучшается.

### 5.4. Приют (станции)
| Станция | Что меняет | Апгрейды |
|---|---|---|
| Вольер | вместимость, место ожидания | +мест, комфорт (быстрее растёт доверие) |
| Мойка | `dirt → 0` | скорость, шампунь (+доверие) |
| Кухня | `hunger → 0` | корм премиум (+здоровье) |
| Ветпункт | `health`, вакцинация | скорость, лечение болезней |
| Операционная | стерилизация | скорость, вторая операционная |
| Бирка/чип | финал, `state = tagged` | — |
| Площадка социализации | `trust ↑`, нужна для пристройства | игрушки |

Станция работает, только когда игрок или волонтёр донёс до неё собаку
(механика из My Perfect Hotel). Нанятые волонтёры берут рутину на себя,
отсюда idle-часть тайкуна.

### 5.5. Экономика
- **Доход:** оплата за обработанную собаку по городскому контракту, пристройство,
  донаты из «безопасных» районов (пассивно, в том числе офлайн), спонсоры.
- **Расходы:** корм, лекарства, зарплаты волонтёров, бензин для фургона.
- Все числа живут в JSON-конфиге (`src/data/balance.json`), баланс правится
  без изменения кода.

### 5.6. Районы
| № | Район | Особенность |
|---|---|---|
| 1 | Гаражи | туториал, 5–8 собак, мало агрессии |
| 2 | Спальный район | дети и прохожие, много пристройства |
| 3 | Рынок | собаки-воришки, быстрые, нужен корм получше |
| 4 | Промзона | большие стаи с вожаками, агрессия |
| 5 | Парк | редкие породы, ночные события |
| 6 | Вокзал | постоянный приток новых собак, финальный район |

Каждый район — отдельная тайловая карта (редактор **Tiled** → JSON → Phaser).

### 5.7. Сохранение
`localStorage` или IndexedDB с автосохранением раз в N секунд и при сворачивании
(`visibilitychange`). При запуске считается офлайн-доход за время отсутствия.

## 6. Управление и UI на телефоне

- **Портретная ориентация** (играется одной рукой, как в hybrid-casual играх).
- **Плавающий джойстик**: палец ставится в любое место нижней половины экрана.
- Контекстная **кнопка действия** справа снизу: «Кинуть корм», «Поймать»,
  «Положить в вольер».
- HUD сверху: деньги, репутация, спокойствие района, кнопка карты города.
- Крупные тач-зоны (не меньше 48 px), учёт safe-area на iPhone (вырез, полоска
  «домой»).
- Масштабирование `Phaser.Scale.FIT` и пиксельная графика без размытия
  (`pixelArt: true`).

```
│  │  ├─ CatchMinigame.ts
│  │  ├─ CareStations.ts
│  │  ├─ Economy.ts
│  │  ├─ Progression.ts         # районы, репутация, анлоки
│  │  ├─ DogGenerator.ts        # процедурные собаки и имена
│  │  └─ SaveSystem.ts
│  ├─ state/GameState.ts        # единое состояние + события (EventEmitter)
│  ├─ data/                     # JSON: районы, станции, баланс, имена, черты

```

Принципы:
- **Состояние отдельно от отображения.** `GameState` — чистые данные, которые
  легко сохранять и тестировать. Сцены его только читают и рисуют.
- **Data-driven.** Районы, станции, цены и черты собак описаны в JSON.
- **Юнит-тесты** (Vitest) на экономику, генератор и прогрессию.

## 9. Принятые решения

1. **Арт:** мультяшный, детализированный пиксель-арт. Всё рисуется кодом
   (`src/art`), с мягким цветным контуром и тёплыми тенями; у каждой собаки
   процедурный окрас, грязь и злые брови исчезают после ухода.
2. **Ориентация:** вертикальная (горизонтальная тоже работает).
3. **Баланс:** сначала всё руками, потом рутину берут на себя нанятые
   работники. Выйти в район и ловить самому можно всегда.
4. **Тон:** уютный.
5. **«Пломбирование»:** бирка или клипса на ухе по ОСВВ.
6. **Хостинг:** репозиторий публичный, поэтому GitHub Pages.
7. **Шрифт:** Tiny5: пиксельный и хорошо читается по-русски
   (у Pixelify Sans кириллическая «в» похожа на «е»).
