# Street Dogs Tycoon

Уютный мобильный тайкун про уличных собак: кормим, ловим, отмываем, лечим, ставим бирку
и делаем районы города спокойнее.

**Играть:** https://kamazichyo.github.io/Testosterone/ (открой на телефоне → «Поделиться» /
меню браузера → «На экран Домой», тогда игра запускается на весь экран и работает офлайн).

План разработки, референсы и архитектура: [docs/PLAN.md](docs/PLAN.md).

## Что уже есть (этапы 0–1)

- Район **«Гаражи»**: гаражный кооператив, хрущёвки, теплотрасса, контейнерная площадка, двор.
- 7 диких собак с характерами (дружелюбные, пугливые, злые), вожак стаи, клички с учётом пола.
- Собаки гуляют, спят, убегают, рычат и кидаются, бегут на запах корма.
- Корм делает собаку добрее: злость падает, доверие растёт; довольную собаку можно поймать.
- Мини-игра ловли «Поймай момент» (злых ловить сложнее), переноска, фургон приюта, монеты от города.
- Подсказки, стрелка к фургону, карточка собаки (голод, грязь, злость, доверие), звуки, вибрация.
- Сохранение прогресса, PWA (офлайн, иконка на экран «Домой»).

Вся графика рисуется кодом (процедурный пиксель-арт), поэтому у каждой собаки уникальный окрас.

## Управление

- **Телефон:** палец в любом месте экрана — джойстик; круглая кнопка справа — действие.
- **Компьютер:** WASD/стрелки — ходьба, Пробел/E — действие.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173 (и по локальной сети — можно открыть с телефона)
npm test           # юнит-тесты (Vitest)
npm run build      # сборка в dist/
npm run icons      # перегенерировать иконки приложения
```

Галерея спрайтов для работы над артом: `npm run dev` → `/dev/preview.html`
(`?map=2` — вся карта района, `?zoom=8` — кадры собак крупно).

Деплой: каждый пуш в ветку по умолчанию собирает игру и публикует на GitHub Pages
(`.github/workflows/deploy.yml`). Один раз нужно включить Pages:
**Settings → Pages → Source: GitHub Actions**.

### Структура

```
src/
  art/        процедурный пиксель-арт: PixelCanvas, собаки, персонаж, пропсы, земля, иконки
  core/       состояние и сохранение, генератор случайных чисел, синтез звуков
  data/       описание района «Гаражи», клички
  dogs/       типы, генератор собак, правила поведения (без Phaser — покрыты тестами)
  entities/   Player, Dog (конечный автомат поведения), FoodPile
  scenes/     Boot (генерация текстур), District (мир), UI (HUD, джойстик, мини-игра)
  ui/         джойстик/метрики экрана, мини-игра ловли, виджеты
tests/        Vitest
```
