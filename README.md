# Street Dogs Tycoon

Уютный мобильный тайкун про уличных собак: кормим, ловим, отмываем, лечим, ставим бирку
и делаем районы города спокойнее.

**Играть:** https://kamazichyo.github.io/Testosterone/ (открой на телефоне → «Поделиться» /
меню браузера → «На экран Домой», тогда игра запускается на весь экран и работает офлайн).

План разработки, референсы и архитектура: [docs/PLAN.md](docs/PLAN.md).

## Что уже есть

**Район «Гаражи»:** гаражный кооператив (один гараж открыт, там дядя Миша чинит машину),
хрущёвки, дорога с разметкой и зеброй, теплотрасса на пустыре, контейнерная площадка,
детская площадка (качели, песочница, турник), выбивалка для ковров, бельё на верёвке.
- Дикие собаки с характерами и вожак. Собаки гуляют, спят, убегают, рычат, бегут на запах
  корма, едят, садятся довольные и идут за тобой, когда доверяют.
- Ловля: корми, пока собака не подобреет → мини-игра «поймай момент» → переноска → фургон.
- Жители и задания: бабушка Зина («покорми трёх собак», потом делится кормом),
  дядя Миша (найти ключ), Петя и Маша (найти мячик).
- Живой двор: голуби взлетают при приближении, кошки шипят на собак, бабочки, падающие
  листья, деревья качаются на ветру, брызги в лужах, пыль из-под ног.
- Находки: косточки (+корм) и монетки. Корм автоматически пополняется у фургона.
- Волны: когда всех поймали, через полторы минуты прибегают новые собаки.
- Собаки, прошедшие уход, возвращаются в район чистыми, с биркой; их можно погладить.

**Приют «Лапа»** (отдельная локация, едешь туда на фургоне):
- Новенькие попадают в загон. Дальше каждую собаку нужно провести через мойку, кухню,
  ветпункт и бирку. Станции работают по таймеру, в том числе пока ты в районе.
- Обработанных собак сажаешь в вольеры. Приходят посетители и забирают собак в семью
  (+40), либо собаку можно выпустить обратно в район (+15).
- Доска улучшений: мешок корма, места в фургоне, новые вольеры, ускорение станций.

**Ощущения:** плавный разгон и торможение героя и собак, камера с упреждением,
подскоки и «сплющивания» при действиях, плавные появления интерфейса, затемнение
при переездах, мягкая виньетка.

## Управление

- **Телефон:** палец в любом месте экрана — джойстик; круглая кнопка справа — действие.
- **Компьютер:** WASD/стрелки — ходьба, Пробел/E — действие, Q — вторая кнопка (поехать).

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173 (и по локальной сети — можно открыть с телефона)
npm test           # юнит-тесты (Vitest)
npm run build      # сборка в dist/
npm run icons      # перегенерировать иконки приложения
```

Галерея спрайтов для работы над артом: `npm run dev` → `/dev/preview.html`
(`?map=2` — вся карта района, `?zoom=8` — кадры собак крупно).

Деплой: каждый пуш в ветку по умолчанию собирает игру и публикует на GitHub Pages
(`.github/workflows/deploy.yml`). Один раз нужно включить Pages:
**Settings → Pages → Source: GitHub Actions**.

### Структура

```
src/
  art/        процедурный пиксель-арт: PixelCanvas, собаки, персонаж, пропсы, земля, иконки
  core/       состояние и сохранение, генератор случайных чисел, синтез звуков
  data/       карты «Гаражей» и приюта, задания жителей, клички
  dogs/       типы, генератор собак, правила поведения и ухода (без Phaser — покрыты тестами)
  entities/   Actor (физика отдельно от спрайта), Player, Dog, DogPuppet, Npc, голуби/кошки/бабочки
  scenes/     Boot (генерация текстур), WorldScene (общая основа), District, Shelter, UI
  ui/         джойстик/метрики экрана, мини-игра ловли, виджеты
tests/        Vitest
```
